# 今日目标提醒与编辑

- 今日目标必须读取 `exactDailyPlan`，不能使用会继承历史目标的 `dailyPlan`，否则未设目标的日期会误显示昨天的任务。
- 手动记录和休息提醒共用 `TodayGoalEditor`，提供空目标提示、添加/修改按钮、双击编辑、保存与取消。保存只更新当天计划，不创建活动记录。
- 保存后通过共享 AppState 更新界面并重新安排定时提醒；跨日重新读取当天目标。
- 本地通知文案在安排时即确定，不能把当天任务放进永久重复通知。改为最多 63 条、未来七天的按日期通知；启动、跨日和修改目标时更新。应用连续退出超过七天后需再次启动才能续排。
- 久用提醒在发出时直接读取当天具体任务；无目标时提示添加。
