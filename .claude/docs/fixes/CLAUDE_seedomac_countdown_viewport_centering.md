# SeedoMac 休息倒计时居中与纯专注时钟适配

## 问题与原因

休息总结和倒计时共用一个 `ScrollView`。固定底部操作栏后，滚动内容仍按自身高度顶部对齐，因此倒计时明显偏上；总结页的滚动位置也不应延续到倒计时页面。

纯专注页使用固定 400 点表盘、120 点数字和 60 点底部留白，小屏幕下可能挤压界面，长时间正计时的数字也可能超出表盘。

## 修复

- 在 `safeAreaInset` 作用的内容区域内测量实际视口，给滚动内容设置视口最小高度：总结顶部对齐，倒计时整体居中。内容超高时仍可滚动。
- 使用状态作为滚动容器身份，进入倒计时时重新建立滚动位置。
- 保留底部按钮栏按实际高度预留空间以及窄屏按钮纵向布局。
- 纯专注表盘根据窗口宽高缩放，低于 800 点高时缩小间距与底部留白。
- 两种表盘的数字限定单行，并允许缩小字号，避免长时间数字溢出。
