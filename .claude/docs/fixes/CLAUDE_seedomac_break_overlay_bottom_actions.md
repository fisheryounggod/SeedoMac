# SeedoMac 提醒页底部操作区布局经验

## 问题

提醒页将底部操作按钮放在 `ScrollView` 之后。总结内容变长时，垂直 `VStack` 会把“稍后、跳过、开始休息、暂停追踪”等按钮推到全屏窗口可视区域之外，表现为底部确认按钮全部消失。

## 修复

- 将底部操作区改为叠加在窗口底部的固定栏。
- 给 `ScrollView` 增加对应的底部内边距，避免最后一段输入内容被固定栏遮挡。
- 固定栏同时承载总结阶段操作和暂停按钮，保证两个状态下按钮始终可见。

## 自适应布局修正

原叠加方案未指定底部对齐，不能保证按钮位于底部。改用 `GeometryReader` 获取每个窗口尺寸，使用 `safeAreaInset(edge: .bottom)` 按操作栏实际高度预留空间，移除固定底部占位。窄屏通过 `ViewThatFits` 将按钮切换为纵向排列；低于 800 点高的窗口缩小标题与间距，倒计时随可用宽高缩放。背景图限制在窗口尺寸内并裁切，避免图片固有比例撑大布局。倒计时的完成按钮也移入固定栏。
