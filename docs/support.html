Recordoo 支持与帮助

感谢使用 Recordoo。应用需要 macOS 14.0 或更高版本。

常见问题

活动追踪没有数据：请在“系统设置 → 隐私与安全性”中检查 Recordoo 所需权限，然后重新启动应用。

日历同步失败：请确认已授予日历访问权限，并在 Recordoo 设置中启用日历同步。

Obsidian 导入或导出失败：请重新选择有效的 Obsidian 仓库或日记文件夹，并确认文件夹具有读写权限。

AI 复盘不可用：请检查你配置的 API 地址、模型名称和 API 密钥。Recordoo 不提供或代管第三方 AI 账户。

报告问题

请前往 GitHub Issues，说明 macOS 版本、Recordoo 版本、复现步骤和错误现象。请勿提交 API 密钥、私人日记内容或其他敏感信息。

隐私

了解数据处理方式，请阅读 Recordoo 隐私政策。
